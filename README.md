# Better West

A mod for the Unity game "Wild West Miner Simulator" that reduces my two annoyances with the game.

## Shovels are better.

Shovels are bumped up in dig amount, but it also has to bump up the drop rate because you're not
uncovering existing resources, the game has a random change to spawn a resource each time you dig.

The top level shovel goes from around 15% to 24% drop rate, which feels right to me.

## Beds also help with sprint amount.

There is a way in the game to upgrade your sprint level, but it takes a while to unlock it. Alongside that, a better
night's sleep will now give you 30 more sprint points every level.

## Using

Install BepInEx 5 (https://docs.bepinex.dev/articles/user_guide/installation/index.html) to the game folder, then drag the 
mod files from the Releases page into the BepInEx/plugins folder in the game directory.

The mod files are open source, so if you feel like they're too generous or not generous enough, feel free to 
fork and modify them yourself. It's a single file, so a basic programming knowledge or an AI would get you there. The
hardest part is installing dotnet and calling dotnet build. If I can build the files from a Linux installation,
you can get it working on Windows.
